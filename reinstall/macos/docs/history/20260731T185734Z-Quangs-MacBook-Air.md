## Lessons Incorporated

- Uniform age encryption is simpler and safer than classifying mixed archives;
  its storage overhead is negligible.
- A binary Markdown checklist is not evidence and cannot represent blocked,
  skipped, or not-applicable work.
- The manual mixed durable procedure with volatile run status and became stale
  across the erase boundary.
- Agents spent unnecessary context rediscovering state from a long manual,
  checklist, manifest, and restored conversation.
- Pre-erase and post-erase need an explicit machine-readable join point.
- Archive creation, metadata, remote verification, and restore staging are
  repetitive and should be scripted with receipts.
- Cleanup must apply the exact reviewed plan and validate every candidate before
  deleting any candidate.
- Zed does not reliably recreate every visible sidebar row from `threads.db`;
  native sidebar rows require a selective merge.
- Trackpad three-finger drag should remain a manual System Settings choice.
- Kanata needs Driver Extension, Input Monitoring, and Accessibility approval,
  plus launchd steady-state verification.
