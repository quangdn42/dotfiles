# Reinstall Workflows

Reinstall workflows are platform-specific. For macOS, start with
[`macos/README.md`](macos/README.md).

For the one-time Omarchy 3.8.4 to 4.0.0 desktop migration, start with
[`omarchy4/README.md`](omarchy4/README.md). It is a human-and-agent runbook,
not an automated migration framework. Remove this temporary entry when the
migration has been accepted; Git history retains the completed runbook.
